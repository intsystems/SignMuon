# Dependencies for the record-#40 NanoGPT-speedrun port. Install into a VENV:
#     bash setup_env.sh
# Never into a Debian system python -- pip cannot uninstall apt-managed packages
# ("Cannot uninstall cryptography 41.0.7: no RECORD file was found").
#
# Two pins differ from upstream modded-nanogpt's requirements.txt, both load-bearing:
#
#   torch==2.10.0   PyPI's 2.10.0 is a cu128 build, and `kernels` fetches a PREBUILT
#                   Flash Attention 3 binary for which the hub has cu126 / cu128 /
#                   cu130 variants only. An NGC container's torch (2.10.0a0+...nv26.01,
#                   CUDA 13.1) would need a cu131 variant that does not exist, so the
#                   container torch cannot be reused for the 8xH100 build.
#
#   kernels<0.13    0.14+ requires huggingface-hub>=1.10 (major bump) and 0.16+ also
#                   sigstore>=4, which pulls cryptography / pyOpenSSL / rfc3161-client.
#                   <0.13 needs only huggingface_hub, packaging, pyyaml, and fetches
#                   FA3 identically.
#
# train_gpt_a100.py needs neither: it uses torch's own FlexAttention, so it runs on
# whatever torch is present, including the container's.

numpy
tqdm
torch==2.10.0
huggingface-hub<2.0,>=0.26.0
kernels>=0.9,<0.13
setuptools
